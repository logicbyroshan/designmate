# About DesignMate — Graphic Designer Portfolio & CMS

## Overview
**DesignMate** is a production-ready, fullstack web application designed and built for **Roshan Damor**, a professional Graphic Designer based in Bhopal, Madhya Pradesh.

The application combines a high-aesthetic, responsive client-facing portfolio with a secured in-browser Content Management System (CMS) that allows real-time management of projects, categories, bio details, and client inquiries without touching code or database shells.

## Key Features & Highlights

### 1. Liquid Topographic Wave Banner
- Electric cobalt & royal blue fluid contour waves matching the Figma design system.
- Bold typography with vertical rotated year indicator (`PORTFOLIO 2026`).

### 2. Divided "MY WORKS" Showcase
- Dynamic grouping of projects by category with custom subtitle headers and count badges.
- Clickable case study modal dialogs displaying client details, tags, high-resolution imagery, and external Behance/live preview links.

### 3. Interactive Lead Capture with Celebration
- "Feeling Confused?" call-to-action with direct email and phone pills.
- Modal contact scheduler with service discipline selector, budget range, and multi-particle canvas confetti celebration upon submission.

### 4. Secured In-Browser CMS (`/manage`)
- Private route accessible exclusively via `/manage`.
- Attempt-throttled passcode gate (lockout after 5 failed attempts).
- Session-persisted admin controls with live Django status indicator, one-click data refresher, and explicit "Exit / Log Out" session destruction.
- Full CRUD management for categories (with 19+ Lucide icon selectors), projects (with high-res multipart uploads up to 50MB), profile bio copy, and client inquiry status updates.
